# wazuh-siem-lab
Hands-on cyber security lab using Wazuh to monitor a Windows endpoint, used to investigate and monitor security alerts and develop threat detection skills.

## Overview
This project documents my practical experience setting up a Wazuh securtiy monitoring lab as a Cyber security student at Edinburgh Napier University.

the overall aim of this is to monitor a windows endpoint, investigate security events and develop new practical threat detection skills.
